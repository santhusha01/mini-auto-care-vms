# Mini Auto Care VMS (4-Day Lite)

Vehicle Service Center Web Application built with Spring Boot 3 (Java 21), React + TypeScript + Vite + Tailwind CSS, and PostgreSQL.

## Monorepo Structure
- `backend/` — Spring Boot 3 API (Modular Monolith)
- `frontend/` — React + TypeScript SPA
- `docs/` — Architecture & EER diagrams
- `postman/` — Postman collections
